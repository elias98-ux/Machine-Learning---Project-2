# Machine Learning - Project 2
This repository for Project 2 of the FYS-STK3155/4155 course. 

The folder "code" includes three Jupyter notebooks containing the code. The first notebook is for part a) - c), the second for d), and the final for part e). Part f) was answered in the conclusion of the PDF report.

Python 3.13.7 was used for all notebooks

The notebook for part e) is set up for the neural network which gave the best accuracy. If other model configurations mentioned in the report need to be tested, the hyper parameters need to be adjusted accordingly. For the regularization parameter and optimizer, the alternatives are in a comment beside the relevant line in the cell which generate the confusion matrix of the neural network.

The folder "PDF" includes a PDF version of the project report.
